# Ministri Public Site

A simple static one-page marketing website designed for GitHub Pages.

## Files

- `index.html` — page content
- `styles.css` — Ministri branding and responsive layout
- `script.js` — current-year footer

## 1. Create the contact form

The form is ready for Formspree, but you must replace:

`https://formspree.io/f/YOUR_FORM_ID`

with the endpoint Formspree gives you.

Typical flow:

1. Create a Formspree account.
2. Create a new form using the Gmail address where you want Ministri enquiries delivered.
3. Copy the form endpoint.
4. Replace `YOUR_FORM_ID` in `index.html`.
5. Submit a test enquiry after the site is published.

## 2. Publish with GitHub Pages

1. Create a new GitHub repository, for example `ministri-website`.
2. Upload these files into the repository root.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save.
8. GitHub will provide a Pages URL.

## 3. Connect your purchased domain

In GitHub Pages settings, add your custom domain.

GitHub will then tell you which DNS records need to be added at your domain provider.

Do not delete or replace existing DNS records until you know what they are used for.

## 5. Before launch

- Replace the Formspree placeholder.
- Add your real domain through GitHub Pages.
- Replace the visual placeholder with real Ministri screenshots later if desired.
- Proofread the public wording and setup offer.
- Test on phone and desktop.
- Send a real contact-form enquiry and confirm it reaches Gmail.
